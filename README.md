# Сумма отрицательных элементов между максимумом и минимумом

## Условие задачи

Дан одномерный массив `A` размерности `N`. Найти сумму отрицательных элементов, расположенных между максимальным и минимальным элементами.

## Уточнения

- «Между» — это элементы, стоящие строго после одного экстремума и строго до другого, независимо от того, какой из них левее.
- Сами максимальный и минимальный элементы в сумму не входят.
- Если экстремумы стоят рядом — сумма равна 0.
- Если одинаковых экстремумов несколько, берётся первый при поиске слева направо.

## Пример

```
A = [5, -3, 8, -1, -7, 2, -4, 9, -6]
```

- Максимум: `9` (индекс 7)
- Минимум: `-7` (индекс 4)
- Между ними: индексы 5 и 6 → `2` и `-4`
- Отрицательный только `-4`
- **Ответ: -4**
